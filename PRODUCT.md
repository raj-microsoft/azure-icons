## Platform
web

## Stack
Delegated within the brief: Vite + vanilla TypeScript. Static GitHub Pages at /azure-icons/.

## Users
Raj Balakrishnan, Microsoft Elevate EMEA Solutions Engineer, and architects preparing diagrams, documentation and training.

## Product Purpose
Find the right official Azure architecture icon instantly and export it without changing its appearance.

## Capabilities and Constraints
Search names and common aliases; filter categories; inspect and copy; download original SVG and transparent 64/256 PNG; select multiple icons for ZIP. Keyboard navigation, deep links, dark/light modes, mobile 390px, reduced motion and AA contrast. No account or tracking. Official V25 November 2026 inputs: 721 SVG files in 29 folders. Deduplicate names while preserving category membership. Public GitHub publication explicitly authorized in the task.

## Brand Commitments
Insanely modern, but unmistakably unofficial and not a Microsoft product. No Microsoft or Azure logo used as this site's brand. Label every icon with its full pack-derived service name. Preserve all shapes and aspect ratios. Clearly surface permitted-use restrictions and official source links.

## Evidence on Hand
src/raw/Azure_Public_Service_Icons/Icons; https://learn.microsoft.com/en-us/azure/architecture/icons/ ; V25 archive linked there. November update table explicitly names four of eight new icons; only verified matches receive the badge.

## Product Principles
- The icon is the content, not decoration.
- Immediate retrieval beats onboarding.
- Preserve source fidelity and terms.
- All core tasks work with keyboard and touch.

## Accessibility & Inclusion
Keyboard navigation, labeled controls, visible focus, contrast AA, reduced-motion support.

## Assumptions
Subagent brief substitutes for an interactive interview: no direct user decision channel. Assumed frequent desktop diagramming use with mobile lookup; light mode follows system preference, with an explicit persistent override. No unapproved factual or commercial claims.
